# Codex project — research_assistant_platform

## Purpose

This directory is the source of truth for the research assistant platform. Codex should use `AGENTS.md` as the mandatory project policy and `PLANS.md` as the implementation roadmap.

## How to work with roles

Use one role per decision or work item. The user can address a role explicitly, for example:

- `PM: prioritize the next milestone.`
- `BA: turn this idea into user stories and acceptance criteria.`
- `Dev: propose the smallest implementation plan.`
- `Tester: design the tests and identify regression risks.`
- `Researcher: define the evaluation protocol.`
- `DevOps: check whether the local runtime is reproducible.`

Roles advise within their responsibility. They do not silently commit, push, deploy or change product scope.

## Standard response format

1. Understanding.
2. Assumptions.
3. Recommendation or implementation proposal.
4. Risks and open decisions.
5. Acceptance criteria or next action.
