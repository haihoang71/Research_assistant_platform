# Codex prompts

## Read-only preflight

Read `AGENTS.md`, the relevant phase file and the applicable documents under `docs/`. Inspect the current repository state. Do not edit files. Report assumptions, risks, affected modules and the proposed acceptance tests.

## Implement one phase

Implement only the selected phase. Preserve existing user changes. Do not change public contracts or architecture documents without recording an ADR. Add tests for both success and failure paths. Run the relevant checks and report evidence.

## Review

Review the selected change for correctness, contract violations, missing tests, citation/provenance risks, security issues and unintended scope expansion. Do not modify files during review.
